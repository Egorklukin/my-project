Шаг 1. Подключаем тип BookStatus
Компонент будет передавать статус книги в styled-компоненты. Для типизации этого значения потребуется BookStatus.

Шаг 2. Добавляем prop status в компонент Cover
Фон обложки будет зависеть от статуса книги.
Задача: Указать, что Cover получает prop status типа BookStatus.

Шаг 3. Добавляем динамический фон обложки
Вместо одного постоянного фона зададим отдельный градиент для каждого статуса.
Задача: Вычислять значение background на основе prop status.
Пояснение:
"done" получает красно-чёрный градиент;
"reading" получает бежево-коричневый градиент;
для "want" возвращается фиолетовый градиент.
Последний return соответствует статусу "want", потому что остальные варианты проверены выше.

Шаг 4. Передаём статус книги в Cover
Styled-компонент уже ожидает prop status, поэтому его необходимо передать в JSX.
Задача: Передать статус текущей книги в обложку.

Шаг 5. Делаем размер названия динамическим
Длинному названию требуется меньший размер шрифта, чтобы оно помещалось на обложке.
Задача: Добавить в CoverTitle числовой prop length и вычислять размер шрифта.
Пояснение:
Функция проверяет количество символов и возвращает подходящий размер:
больше 40 символов — 8px;
больше 28 — 10px;
больше 16 — 12px;
16 и меньше — 16px.
Проверки располагаются от наибольшего значения к наименьшему.

Шаг 6. Передаём длину названия
Количество символов можно получить через свойство строки length.
Задача: Передать длину названия книги в CoverTitle.

Шаг 7. Добавляем prop status в компонент Badge
Оформление метки также будет зависеть от статуса книги.
Задача: Типизировать prop status для компонента Badge.

Шаг 8. Делаем цвет текста динамическим
Каждый статус получит собственный цвет текста.
Задача: Добавить вычисление свойства color.

Шаг 9. Делаем фон метки динамическим
Цвет фона должен соответствовать выбранному статусу.
Задача: Добавить вычисление свойства background-color.

Шаг 10. Добавляем индикатор статуса
Перед текстом метки разместим небольшой цветной круг с помощью псевдоэлемента.
Задача: Создать ::before и изменить его цвет в зависимости от статуса.

Практика. Базовая часть
Шаг 1. Подключаем useState и тип Book
Массив книг будет храниться в состоянии компонента App.
Для его типизации потребуется интерфейс Book.
Задача: Импортировать useState и тип книги.

Шаг 2. Переносим массив книг в состояние
Сейчас компоненты напрямую получают обычную константу
initialBooks. Перенесём этот массив в состояние App.
Задача: Создать состояние с массивом книг.

Шаг 3. Передаём состояние дочерним компонентам
Stats и BookList должны использовать текущее состояние,
а не начальную константу.
Задача: Заменить initialBooks в JSX на books.

Шаг 4. Создаём функцию удаления книги
Для удаления потребуется получить идентификатор книги
и создать новый массив без неё.
Задача: Создать в App функцию deleteBook.

Шаг 5. Передаём функцию в BookList
Компонент BookList находится между App и отдельными
карточками. Поэтому функция удаления сначала передаётся ему.
Задача: Передать deleteBook через props.

Шаг 6. Типизируем новый prop в BookList
Компонент должен принимать функцию, которая
получает числовой идентификатор и ничего не возвращает.
Задача: Добавить deleteBook в интерфейс BookListProps.

Шаг 7. Получаем функцию в BookList
После добавления prop в интерфейс его необходимо
получить в параметрах компонента.
Задача: Деструктурировать deleteBook.

Шаг 8. Передаём функцию каждой карточке
BookList не знает, по какой карточке нажмёт
пользователь. Поэтому одна функция передаётся
каждой созданной карточке.
Задача: Добавить prop deleteBook компоненту BookCard.

Шаг 9. Типизируем функцию в BookCard
Карточка должна получить объект книги и функцию удаления.
Задача: Добавить deleteBook в BookCardProps.

Шаг 10. Подключаем удаление к кнопке
В карточке уже есть кнопка удаления. Добавим ей
обработчик нажатия.
Задача: Вызвать deleteBook с идентификатором текущей книги.

Шаг 11. Добавляем сообщение для пустого списка
После удаления последней книги вместо пустого
контейнера должно появиться сообщение.
Задача: Создать styled-компонент для сообщения.

Шаг 12. Добавляем условную разметку
Если массив пуст, отображается сообщение. Если в
нём есть книги, создаётся список карточек.
Задача: Проверить длину массива перед выводом List.
